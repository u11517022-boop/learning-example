markdown# 🚀 大一網頁作品集雛型 | My Portfolio Website

這是一個專為記錄大學四年成長軌跡所設計的**個人作品集網頁**。本專案目前做為**大一課堂作業**的起點，採用現代感的深色調（Dark Mode）視覺美學，並建立了一個結構清晰、具備擴充性的網頁雛型，未來將持續記錄大一到大四的所有精采作品與技術沉澱。

---

## ✨ 專案特色 (Features)

* **現代暗黑風格**：採用 `#0f172a` 藍黑調美學，搭配亮藍色（Sky Blue）重點高亮，視覺舒適且具科技感。
* **語意化 HTML5**：善用 `<header>`、`<main>`、`<section>`、`<footer>` 等語意化標籤，結構清晰好維護。
* **彈性網格佈局**：作品集區塊採用 CSS Grid（網格排版），具備良好的裝置自適應與擴充潛力。
* **便利的變數管理**：使用 CSS Variables 統一管理全站色彩，方便未來一鍵切換主題（如明亮模式）。

---

## 🛠️ 使用技術 (Technologies)

* **HTML5**：建構語意化的網頁骨架。
* **CSS3**：負責全站視覺樣式、CSS Grid 佈局以及原生自訂變數（Variables）。

## 📦 如何在本地端執行 (Getting Started)

這個專案非常輕量，不需要安裝任何後端環境或編譯套件（如 Node.js），只需跟著以下步驟即可在電腦上瀏覽：

1. **複製本專案到本地電腦**：
   ```bash
   git clone https://github.com
   ```
2. **開啟網頁**：
   直接用滑鼠雙擊點開 `index.html` 檔案，即可在任意瀏覽器（如 Chrome, Edge, Safari）中觀看效果。
3. **💡 開發推薦**：
   建議使用 **VS Code** 編輯器，並安裝 **Live Server** 擴充套件，即可享受修改程式碼後「網頁即時自動重新整理」的流暢開發體驗！
